Automation Engineer with **2–3 years of experience** in Playwright automation for web applications. Strong understanding of test automation fundamentals, UI automation, and CI integration. Passionate about writing clean, maintainable test code.

---

- Automation: Playwright, Selenium (basic)
- Language: JavaScript, TypeScript
- Testing: UI Automation, Regression Testing
- Frameworks: Page Object Model (POM)
- CI/CD: GitHub Actions, Jenkins (basic)
- Tools: Git, VS Code, Postman
- Browsers: Chromium, Firefox, WebKit

---

### 💼 Professional Experience
**Automation Engineer**  
*ABC Technologies* | 2023 – Present

- Developed Playwright automation scripts for critical UI flows
- Implemented Page Object Model for better maintainability

- Identified and reported defects with clear repro steps
- Collaborated with developers and manual testers

---

### 📌 Key Achievements
- Reduced manual testing effort by 40%
- Improved test stability using Playwright auto-waiting
- Automated smoke tests for CI pipeline
